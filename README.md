# 视频压缩与格式转换器

一个完全本地运行的桌面浏览器界面工具，基于 **NiceGUI** 和 **PyAV**（FFmpeg Python 绑定）处理视频。不会上传文件到外部服务。

## 功能

- 将常见视频输出为 MP4 H.264、MP4 H.265/HEVC、M4V、MOV、WebM、MKV、MPEG-TS、FLV 或 AVI
- 使用 CRF（恒定质量）压缩：数值越小越清晰、文件通常越大
- 提供编码预设，在速度和压缩率间取舍
- 可选缩放（保持原始宽高比）和调整输出帧率
- 保留首个音频流；没有音频的视频同样可处理
- 可一次选择最多 50 个文件，使用受控多进程池并行转换
- 支持将视频文件或视频文件夹直接拖入窗口；也可使用 Windows 原生窗口选择文件/文件夹并递归扫描
- 队列表格展示每个视频的编码、源分辨率、帧率、时长和源码率
- 可逐文件设置目标 CRF、最大宽度、输出帧率与目标码率，适用于个性化批量转换
- 使用 Windows 原生“选择自定义输出目录”窗口选择保存位置，默认是当前用户的 `Downloads` 文件夹
- 转换完成后直接保存到所选目录或原文件夹；上传用临时文件会在关闭程序时清理
- 保留 NiceGUI 官方明亮 / 黑暗模式切换

## 安装与运行

建议使用 Python 3.10 或更新版本，并确保系统可以使用 FFmpeg 相关编解码器（多数 PyAV 预编译包已自带）。

```powershell
cd C:\work\project\Max-s-Treasure-Box\tools\video-compressor-converter
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

打开终端显示的本地地址，可一次选择多个视频文件，再设置参数并开始处理。上传控件尾部的对号只表示该浏览器文件已经上传到本地处理队列；请以页面中“待转换队列”的文件数为准，也可以从该队列单独移除文件或一键清空。点击“选择自定义输出目录”会打开 Windows 原生文件夹选择窗口。若同名文件已经存在，工具会自动添加 `_1`、`_2` 等序号，避免覆盖已有文件。

可将一个或多个视频文件、一个或多个视频文件夹混合拖到同一个上传区，文件夹中的视频会逐个加入队列表格。通过“从本机选择文件”或“选择文件夹并扫描”添加时，工具直接读取原始文件而不复制大文件，并会递归扫描子文件夹。

选择文件完成后，队列会以表格展示源文件的编码、分辨率、帧率、时长、码率及文件体积。可直接修改每一行的“目标 CRF”“目标宽度”“目标 FPS”“目标码率 kbps”：宽度和 FPS 留空将保留源参数；目标码率留空则使用 CRF 恒定质量编码，填写目标码率后该文件以指定码率进行编码。每行的“输出位置”可选“自定义输出目录”或“原文件夹输出”，输出位置下拉会立即写回当前行；也可用批量按钮一次性覆盖队列输出位置。“原文件夹输出”仅适用于通过 Windows 本机选择文件/目录加入的文件，因为浏览器拖放上传受安全机制限制，无法提供原始磁盘目录。

批量开始后，每个文件会显示“排队中 / 转换中 / 完成 / 失败”等任务状态。工具会通过独立的 Python 进程并行编码多个视频，不再等待前一个文件完成才开始下一个。可使用“批量并行数”设置同时转换的文件数，默认取 CPU 核心数和 `8` 中的较小值。CPU 较弱、内存有限或文件分辨率很高时，建议设置为 `1–2`；性能较好的多核电脑可设置为 `4–8`。

CRF、目标宽度、FPS 和目标码率均为“常用值下拉 + 手动输入”组合框：可以直接选择 720P/1080P/4K 等常见宽度、24/30/60 FPS 等常见帧率，也可以输入自己的数值。目标宽度、FPS、码率留空表示保持源参数或使用 CRF 模式。

页面右上角的“黑暗模式”开关使用 NiceGUI 官方明亮 / 黑暗主题。

## 输出格式建议

| 场景 | 建议预设 |
| --- | --- |
| 手机、电视、会议软件和通用分享 | MP4 (H.264 + AAC，通用兼容) |
| 更小的归档文件，设备支持 HEVC | MP4 (H.265 / HEVC + AAC，更小体积) |
| Apple 生态或剪辑软件导入 | M4V / MOV (H.264 + AAC) |
| 网页播放 | WebM (VP9 + Opus) |
| 保留灵活封装或高质量归档 | MKV (H.264 / H.265 / VP9) |
| 电视、广播、流媒体工作流 | MPEG-TS (H.264 + AAC) |
| 旧式直播平台兼容 | FLV (H.264 + AAC) |

## 参数建议

| 目标 | 格式 | CRF | 预设 |
| --- | --- | --- | --- |
| 通用分享 | MP4 | 23 | medium |
| 更小文件 | MP4 | 28 | slow |
| 网页播放 | WebM | 33 | good |
| 尽量保留质量 | MKV / MP4 | 18 | slow |

> CRF 的有效范围为 0–51。不同编码器对 CRF 的视觉效果不同；若输出体积或画质不符合预期，可每次调整 3–5 再试。

## 注意

- 转码耗时取决于视频长度、分辨率、CPU 和编码预设；处理期间请保持页面开启。
- AV1、HEVC 等非常规源格式能否读取，取决于当前 PyAV/FFmpeg 构建是否带有相应解码器。
- 本工具不修改原文件。
